<h1>🎮 Alugames</h1>

<h2>🧩 Sobre o projeto</h2>
<p> O Alugames é uma aplicação que simula um catálogo de jogos, permitindo aos usuários visualizar, filtrar e "alugar" títulos. O foco principal é a interação com arrays, a manipulação de objetos e a renderização dinâmica de conteúdo (como cartões de jogos) na tela.
